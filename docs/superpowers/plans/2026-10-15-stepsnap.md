# StepSnap — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu bar утилита для macOS: на каждый клик в выбранном окне (эмулятор iOS/Android, браузер) делает снимок именно этого окна и в конце собирает из шагов PDF-отчёт.

**Architecture:** Два таргета SwiftPM. Библиотека `StepSnapCore` — вся логика и вся математика (координаты, фильтр окон, раскладка страниц, манифест, сессия записи), покрыта swift-testing. Исполняемый `StepSnap` — тонкая обвязка на AppKit (NSStatusItem + NSPopover, HUD), SwiftUI и ScreenCaptureKit. Сборка в `.app`-бандл скриптом, ad-hoc подпись.

**Tech Stack:** Swift 6.1.2 (транспайлер), Swift 5 language mode, SwiftUI + AppKit, ScreenCaptureKit, Core Graphics + Core Text, SwiftPM, swift-testing.

**Spec:** `docs/superpowers/specs/2026-10-15-stepsnap-design.md` — план спорит со спекой, поэтому спека идёт вместе с планом. Исполнителю читать обе.

## Global Constraints

- Минимальная версия macOS — 14.0: `platforms: [.macOS(.v14)]`. Проверяется на macOS 15.6, Xcode 16.4, Swift 6.1.2.
- `swift-tools-version: 6.0` и `swiftLanguageModes: [.v5]`. Причина: `CGImage` и типы AppKit не `Sendable`, строгий режим Swift 6 добавляет трение без пользы для одноразовой локальной утилиты. Состояние UI живёт под `@MainActor`.
- Сторонних зависимостей нет.
- Тест-фреймворк — swift-testing: `import Testing`, `@Test`, `#expect`, команда `swift test`. Проверено на этом тулчейне.
- Тесты есть только у `StepSnapCore`. Код приложения проверяется сборкой и ручным прогоном, для каждого шага указано, что именно смотреть.
- Язык интерфейса и текстов отчёта — русский. Имена и комментарии в коде — английские.
- Значения из спеки, копировать точно: A4 = 595 × 842 pt; поля 48 pt; максимальная высота картинки 620 pt; высота подписи 26 pt; отступ подписи до картинки 6 pt; отступ между шагами 24 pt.
- Папка по умолчанию: `~/Documents/StepSnap`. Манифест: `steps.json`. PDF: `отчёт.pdf`. Снимки: `step-001.png` (номер тремя цифрами).
- Папка сценария: `<санитизированное имя>-<yyyy-MM-dd>-<HHmmss>`; при пустом результате санитизации имя = `сценарий`; максимум 60 символов.
- Задержка перед снимком: по умолчанию 250 мс, диапазон 0…5000.
- Минимальный размер окна в списке: 200 × 200 pt. Берутся только окна с `kCGWindowLayer == 0` и чужих процессов.
- Разрешение одно: «Запись экрана». Универсальный доступ не запрашивается.
- `CFBundleIdentifier` = `local.stepsnap`, `LSUIElement = true`, `NSPrincipalClass` = `NSApplication`, песочница выключена.
- Бандл всегда собирается в `build/StepSnap.app` — путь не менять: TCC запоминает разрешения по бандлу.
- Тексты ошибок пользователю — по-русски, без внутренних деталей (без имён типов и стеков).

## Review Focus

Спека — документ о замысле, она не перечисляет всё, что встретится. Пять классов входных
данных, которые вероятнее всего укусят живого пользователя, и где именно они закреплены
тестом:

1. **Окно на втором мониторе.** Точка клика на дисплее, который начинается правее основного (в координатах Core Graphics — с ненулевым смещением). Ожидание: шаг создаётся, относительная точка клика верна. Тест в Task 5.
2. **Имя сценария, из которого не получается нормальное имя папки:** пустая строка, одни пробелы, `../../etc`, эмодзи, 500 символов. Ожидание: папка создаётся внутри выходной папки и имеет непустое имя не длиннее 60 символов; запись за пределы выходной папки невозможна. Тесты в Task 4 и Task 7.
3. **Целевое окно закрылось или снимок не получился.** Ожидание: шаг не исчезает молча — он остаётся в манифесте и в PDF с пометкой об ошибке; манифест остаётся валидным; отчёт сохраняется. Тесты в Task 7 и Task 8.
4. **Быстрая серия кликов.** Ожидание: порядок шагов совпадает с порядком кликов, номера файлов не перемешиваются, задержка не накапливается. Тест в Task 7.
5. **Клик по HUD в области целевого окна.** Ожидание: шаг не создаётся, потому что верхнее окно под курсором — HUD. Тест в Task 5.

public enum CoordinateMapper {
    public static func coreGraphicsPoint(appKitPoint: CGPoint, primaryScreenHeight: CGFloat) -> CGPoint

public struct NormalizedPoint: Codable, Equatable, Sendable {
    public var x: Double

    public static func from(point: CGPoint, inWindowBounds bounds: CGRect) -> NormalizedPoint?

    case step(point: CGPoint, normalized: NormalizedPoint?)

}
