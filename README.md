# StepSnap

Утилита в строке меню macOS для QA: на каждый клик мышью внутри выбранного окна делает снимок
именно этого окна и в конце собирает PDF-отчёт с шагами.

Заменяет ручную цепочку «сделал действие → сделал скриншот → сохранил → описал шаг → склеил
отчёт». Работает с чем угодно, у чего есть окно: эмулятор iOS, эмулятор Android, браузер.

## Требования

- macOS 14 или новее
- Xcode или Command Line Tools (нужен Swift 6)
- Разрешение «Запись экрана»

## Сборка и запуск

```bash
./run.sh     # собрать и запустить
./build.sh   # только собрать
swift test   # прогнать тесты
```

Собирается в `build/StepSnap.app`. Скрипт подписывает приложение сертификатом, найденным в
связке ключей; если сертификата нет — ad-hoc подписью. С ad-hoc подписью macOS считает каждую
пересборку новым приложением, и разрешение на запись экрана приходится выдавать заново.
Сертификат (`Apple Development` или `Developer ID`) это лечит.

`STEPSNAP_SIGN_IDENTITY="имя сертификата" ./build.sh` — подписать конкретным сертификатом.

## Первый запуск

1. В строке меню появится иконка камеры. В доке приложения нет — это нормально.
2. Выдать разрешение: Системные настройки → Конфиденциальность и безопасность → Запись экрана.
3. Перезапустить приложение: без перезапуска первый снимок выйдет пустым.

Универсальный доступ (Accessibility) не нужен — только запись экрана.

## Как пользоваться

1. Иконка → **Новый сценарий** → название → **Продолжить**.
2. Выбрать окно-источник из списка открытых окон.
3. Работать в этом окне как обычно: каждый клик внутри него становится шагом со снимком.
   Клики по другим окнам и по панелям самого приложения в отчёт не попадают.
4. **Пауза** в панели записи — чтобы пройти навигацию к нужному экрану, не засоряя отчёт.
5. **Стоп** — собрать отчёт.

Папка по умолчанию: `~/Documents/StepSnap/<сценарий>-<дата>/`, внутри `отчёт.pdf`,
`steps.json` и снимки шагов. Папка, режим подписи, задержка перед снимком и отметка точки
клика меняются в настройках.

Если приложение закрыть во время записи, при следующем запуске оно предложит дособрать отчёт
по оставшимся шагам.

## Устройство

- `Sources/StepSnapCore` — вся логика и математика: маршрутизация кликов, координаты, сессия
  записи, манифест, раскладка страниц, PDF, восстановление. Покрыта тестами.
- `Sources/StepSnap` — обвязка: AppKit, SwiftUI, ScreenCaptureKit.
- `docs/superpowers` — дизайн и план реализации, с решениями и их причинами.

Приложение не прописывается в автозапуск: после перезагрузки его нужно запускать вручную.
